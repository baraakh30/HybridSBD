\begin{abstract}
This document presents results from threshold-based shot boundary detection experiments. Four feature extraction techniques (CNN, HSV Histogram, CLIP, Optical Flow) were tested with different preprocessing strategies (raw, smoothed, normalized-smoothed) and two detection methods (simple, constrained) across 10 videos. We further introduce \textbf{Locally Adaptive Robust Detection} methods that use median and MAD-based normalization with grid-searched optimal parameters, achieving significant performance improvements (up to \textbf{F1=0.536} with sampling, \textbf{F1=0.525} without sampling).
\end{abstract}

\section{Introduction}

Threshold-based detection identifies shot boundaries by detecting peaks in frame-to-frame dissimilarity scores. This report presents experimental results from testing multiple feature types and preprocessing configurations.

\section{Methodology}

\subsection{Feature Extraction Methods}
\begin{itemize}
    \item \textbf{CNN}: Deep convolutional features
    \item \textbf{HSV Histogram}: Color distribution
    \item \textbf{CLIP}: Vision-language embeddings
    \item \textbf{Optical Flow}: Motion features
\end{itemize}

\subsection{Preprocessing}
\begin{itemize}
    \item \textbf{Raw}: No preprocessing
    \item \textbf{Smoothed}: Gaussian smoothing
    \item \textbf{Normalized-Smoothed}: Z-score normalization + smoothing
\end{itemize}

\subsection{Detection Methods}

\subsubsection{Baseline Methods}
\begin{itemize}
    \item \textbf{Simple}: All peaks above threshold
    \item \textbf{Constrained}: Minimum distance between detections
\end{itemize}

\subsubsection{Locally Adaptive Robust Detection (New)}
The adaptive detection algorithm introduces robust local normalization using median and Median Absolute Deviation (MAD), making it more resilient to outliers and varying signal characteristics:

\begin{enumerate}
    \item \textbf{Local Window ($w$)}: Radius for local window (detection resolution)
    \item \textbf{Statistics Multiplier ($k$)}: Expands window to $2kw$ frames for robust statistics
    \item \textbf{Sensitivity Factor ($\alpha$)}: Threshold in normalized space (boundary when $\hat{C}_i < -\alpha$)
    \item \textbf{Normalized Score}: $\hat{C}_i = \frac{C_i - \text{median}(W_i)}{\text{MAD}(W_i)}$
    \item \textbf{Minimum Scene Length ($L_{min}$)}: Prevents over-segmentation
    \item \textbf{Dissolve Handling ($W_{max}$)}: Groups consecutive candidates for gradual transitions
\end{enumerate}

\subsection{Configurations}
\begin{itemize}
    \item \textbf{No Sampling}: Every frame processed
    \item \textbf{Sampling (Rate=8)}: Every 8th frame
\end{itemize}

\subsection{Key Findings}

\subsubsection{Baseline Detection Findings}
\begin{itemize}
    \item \textbf{With Sampling}: Normalized-smoothed preprocessing essential. Raw/smoothed yield near-zero performance.
    \item \textbf{Without Sampling}: Raw features perform well, especially CLIP (F1=0.671) and CNN (F1=0.427).
    \item \textbf{Simple detection}: High recall ($>$0.95) but very low precision ($<$0.05), causing massive over-detection.
    \item \textbf{Constrained detection}: 2-10x precision improvement, maintaining reasonable recall (0.5-0.7).
\end{itemize}

\subsubsection{Adaptive Detection Findings (New)}
\colorbox{highlight}{\parbox{\dimexpr\linewidth-2\fboxsep}{%
\textbf{Major Improvements with Adaptive Detection V3:}
\begin{itemize}
    \item \textbf{With Sampling}: HSV Histogram achieves \textbf{F1=0.536} (+10\% over baseline 0.488)
    \item \textbf{With Sampling}: CLIP improves dramatically from F1=0.269 to \textbf{F1=0.523} (+94\%)
    \item \textbf{With Sampling}: CNN improves from F1=0.348 to \textbf{F1=0.520} (+49\%)
    \item \textbf{Without Sampling}: CNN achieves \textbf{F1=0.510} (+19\% over baseline 0.427)
    \item \textbf{Robust normalization}: Median/MAD-based normalization reduces sensitivity to outliers
    \item \textbf{Grid search}: Optimal parameters vary significantly by feature type and sampling rate
\end{itemize}
}}

\subsubsection{Parameter Insights}
\begin{itemize}
    \item \textbf{Window size ($w$)}: Smaller windows ($w=3-5$) work better for color features (HSV), larger ($w=10$) for semantic features (CLIP)
    \item \textbf{Statistics multiplier ($k$)}: $k=3-4$ provides good balance between stability and responsiveness
    \item \textbf{Sensitivity ($\alpha$)}: Higher values ($\alpha=4.0-5.0$) reduce false positives; lower values needed for subtle transitions
    \item \textbf{Optical Flow}: Remains challenging; requires lower $\alpha$ due to noisy motion signals
\end{itemize}

\section{Discussion}

Frame sampling fundamentally changes optimal preprocessing: normalization becomes essential with sampling, while raw features excel without sampling. Constrained detection is critical to reduce false positives. HSV Histogram provides consistent performance across configurations, while CLIP achieves best results with full-frame processing.

\subsection{Adaptive Detection Benefits}

The locally adaptive robust detection algorithm provides several advantages:

\begin{enumerate}
    \item \textbf{Robustness to Outliers}: Median and MAD statistics are resistant to extreme values, unlike mean/std-based methods
    \item \textbf{Local Adaptation}: The algorithm adapts to varying signal characteristics throughout the video
    \item \textbf{Parameter Optimization}: Grid search identifies optimal parameters for each feature/sampling combination
    \item \textbf{Dissolve Handling}: Consecutive candidate grouping handles gradual transitions naturally
    \item \textbf{Consistent Improvements}: With sampling, all features show improvement (+2\% to +94\%)
\end{enumerate}

\subsection{Trade-offs}

\begin{itemize}
    \item \textbf{No Sampling + CLIP}: Baseline (F1=0.671) outperforms adaptive (F1=0.447), suggesting raw CLIP features have inherently good separation
    \item \textbf{No Sampling + HSV}: Similar performance (0.567 vs 0.525), baseline slightly better
    \item \textbf{Sampling scenarios}: Adaptive detection consistently outperforms baseline across all features
\end{itemize}

\subsection{Limitations}
\begin{itemize}
    \item May not capture complex transitions (dissolves, fades)
    \item Performance varies by video type
    \item Optical flow has low precision
    \item High false positive rates with simple detection
    \item Grid search is computationally expensive
    \item Optimal parameters may not generalize to unseen videos
\end{itemize}

\section{Conclusion}

\subsection{Baseline Results}
HSV Histogram with normalized-smoothed preprocessing and constrained detection provides consistent results (F1=0.488-0.567). CLIP achieves superior performance (F1=0.671) with full temporal resolution. Constrained detection reduces false positives by orders of magnitude while maintaining good recall.

\subsection{Adaptive Detection Results}

\colorbox{bestresult}{\parbox{\dimexpr\linewidth-2\fboxsep}{%
\textbf{Key Achievements with Adaptive Detection V3:}
\begin{itemize}
    \item \textbf{Best with Sampling:} HSV Histogram achieves F1=0.536 with parameters $w=5$, $k=2$, $\alpha=4.0$
    \item \textbf{Best without Sampling:} HSV Histogram achieves F1=0.525 with parameters $w=3$, $k=3$, $\alpha=5.0$
    \item \textbf{Largest Improvement:} CLIP with sampling improved by 94\% (0.269 → 0.523)
    \item \textbf{Most Consistent:} CNN shows strong performance across both configurations (F1≈0.51-0.52)
\end{itemize}
}}

\subsection{Recommendations}

\begin{enumerate}
    \item \textbf{With Frame Sampling}: Use Adaptive V3 with HSV Histogram ($w=5$, $k=2$, $\alpha=4.0$) or CLIP ($w=10$, $k=4$, $\alpha=4.0$)
    \item \textbf{Without Frame Sampling}: Use baseline CLIP (Raw, Simple) for best single-feature performance, or Adaptive V3 HSV for more balanced precision/recall
    \item \textbf{For Robustness}: Adaptive detection V3 provides more consistent results across varying video content
    \item \textbf{For Speed}: Frame sampling (rate=8) with adaptive detection provides good accuracy with 8x fewer frames to process
\end{enumerate}
