\begin{abstract}
This document presents results from threshold-based shot boundary detection experiments. Four feature extraction techniques (CNN, HSV Histogram, CLIP, Optical Flow) were tested with different preprocessing strategies (raw, smoothed, normalized-smoothed) and two detection methods (simple, constrained) across 10 videos, comparing performance with and without frame sampling (rate=8).
\end{abstract}

\section{Introduction}

Threshold-based detection identifies shot boundaries by detecting peaks in frame-to-frame dissimilarity scores. This report presents experimental results from testing multiple feature types and preprocessing configurations.

\section{Methodology}

\subsection{Feature Extraction Methods}
\begin{itemize}
    \item \textbf{CNN}: Deep convolutional features
    \item \textbf{HSV Histogram}: Color distribution
    \item \textbf{CLIP}: Vision-language embeddings
    \item \textbf{Optical Flow}: Motion features
\end{itemize}

\subsection{Preprocessing}
\begin{itemize}
    \item \textbf{Raw}: No preprocessing
    \item \textbf{Smoothed}: Gaussian smoothing
    \item \textbf{Normalized-Smoothed}: Z-score normalization + smoothing
\end{itemize}

\subsection{Detection Methods}
\begin{itemize}
    \item \textbf{Simple}: All peaks above threshold
    \item \textbf{Constrained}: Minimum distance between detections
\end{itemize}

\subsection{Configurations}
\begin{itemize}
    \item \textbf{No Sampling}: Every frame processed
    \item \textbf{Sampling (Rate=8)}: Every 8th frame
\end{itemize}

\subsection{Key Findings}

\begin{itemize}
    \item \textbf{With Sampling}: Normalized-smoothed preprocessing essential. Raw/smoothed yield near-zero performance.
    \item \textbf{Without Sampling}: Raw features perform well, especially CLIP (F1=0.671) and CNN (F1=0.427).
    \item \textbf{Simple detection}: High recall ($>$0.95) but very low precision ($<$0.05), causing massive over-detection.
    \item \textbf{Constrained detection}: 2-10x precision improvement, maintaining reasonable recall (0.5-0.7).
\end{itemize}

\section{Discussion}

Frame sampling fundamentally changes optimal preprocessing: normalization becomes essential with sampling, while raw features excel without sampling. Constrained detection is critical to reduce false positives. HSV Histogram provides consistent performance across configurations, while CLIP achieves best results with full-frame processing.

\subsection{Limitations}
\begin{itemize}
    \item May not capture complex transitions (dissolves, fades)
    \item Performance varies by video type
    \item Optical flow has low precision
    \item High false positive rates with simple detection
\end{itemize}

\section{Conclusion}

HSV Histogram with normalized-smoothed preprocessing and constrained detection provides consistent results (F1=0.488-0.567). CLIP achieves superior performance (F1=0.671) with full temporal resolution. Constrained detection reduces false positives by orders of magnitude while maintaining good recall.
